# Architecture Decision Records (ADR)

Записи о значимых архитектурных решениях. Формат: `NNNN-краткое-название.md`.

ADR фиксирует **почему** решение принято, какие были альтернативы и какие последствия.
Через год это важнее самого кода: код показывает «как», ADR — «почему именно так».

## Формат

```markdown
# NNNN. Название решения

Дата: ГГГГ-ММ-ДД
Статус: Принято | Заменено на NNNN | Отклонено

## Контекст
Что заставило принимать решение. Ограничения, требования, силы.

## Рассмотренные варианты
1. Вариант A — плюсы и минусы
2. Вариант B — плюсы и минусы

## Решение
Что выбрано и почему.

## Последствия
Что становится проще, что сложнее, что придётся делать в будущем.
```
